Build a production-style SaaS web application called **AI QA Copilot**.

The product is an AI-powered Quality Engineering and Software Testing platform for QA engineers, QA leads, developers, and engineering teams.

PRIMARY PRODUCT PROMISE:

"From requirement to release confidence."

The platform should help teams move through:

Requirement
→ Requirement Analysis
→ Risk Analysis
→ Test Design
→ Test Cases
→ Test Data
→ API Testing
→ UI Automation
→ Test Execution
→ Defect Management
→ QA Reporting
→ Release Quality Summary

IMPORTANT:
I am a non-coding user and I want Lovable to build the application for me.

Build a REAL application foundation, not merely a marketing landing page or static prototype.

The UI, navigation, data structures, workflows and components should be designed as if this could eventually become a commercial enterprise QA product.

Where external AI/API functionality is unavailable, create clean service interfaces and realistic demo/mock data so the application remains usable.

Do not expose API keys in frontend code.
